2. C4 and UML recommendations were treated as guidance, not as automatic authority. Actor generalization, `include`, `extend`, system boundaries, and diagram abstraction levels were reviewed against the team's intended model.

3. The Technology Stack document describes the current repository and its approved architecture. AI suggestions for future infrastructure or services were not presented as implemented features unless repository evidence supported them.

5. Git history, repository files, weekly reports, team decisions, rendered assets, and implementation tests remain the authoritative evidence of the work. Chat screenshots and exact access times must be added from the original Codex history if they are required for the final submission.
