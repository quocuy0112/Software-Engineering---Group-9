## 1. Executive Summary

The source report surveys three recruitment platforms - **VietNamWorks**, **TopCV**, and **LinkedIn** - to extract common UX/design patterns and inform the design of a proposed next-generation recruitment platform. Each platform is positioned around a distinct core value:

| Platform         | Core Focus                                                   |
| ---------------- | ------------------------------------------------------------ |
| **VietNamWorks** | Efficient, high-volume job matching                          |
| **TopCV**        | Candidate preparation (CV-building, job search fundamentals) |
| **LinkedIn**     | Professional networking at scale                             |

The proposed platform aims to combine all three strengths under one AI-native, more accessible experience.

## 2. Cross-Platform Common Ground

### 2.1 Core Modules

Authentication · Candidate profile · Job search · Advanced filtering · Job details · Company profile · Apply workflow · Saved jobs · Job alerts · Recruiter dashboard · Notifications · Messaging · Responsive UI

### 2.2 Shared UX Patterns

Card-based layouts · Search-first navigation · Multi-step forms · Progressive disclosure · Personalized recommendations · Dashboard metrics · Profile completeness indicators · Company branding · Email notifications · AI-assisted recommendations

### 2.3 Shared Design Patterns

White backgrounds · Blue/green primary action colors · Component reuse · Responsive layouts · Top-anchored search · Sidebar navigation · CTA-driven page structure

## 3. VietNamWorks

### 3.1 Focus

Job-matching efficiency, with a rich, feature-dense candidate experience.

### 3.2 Survey Scope

The most granular of the three surveys, covering:

- Homepage (nav bar, featured employers, recommended jobs, senior/experienced roles, CV builder & career assessment tools, media recognition/reviews)
- Job search & filtering (advanced search bar, result filters)
- Job & company detail pages
- Account/profile management (login, dashboard, CV management, applied/saved jobs, followed companies)

### 3.3 Strengths & Weaknesses

- **Strengths:** Mature information architecture, consistent navigation, rich filtering, strong candidate journey, employer-oriented workflow, scalable components.
- **Weaknesses:** High information density, repeated UI patterns, some accessibility gaps, complex navigation for new users, limited personalization in parts of the flow.

## 4. TopCV

### 4.1 Focus

Candidate preparation - helping users build strong applications rather than just browse listings.

### 4.2 Survey Scope

A leaner survey focused on core transactional flows:

- Authentication/login (incl. social login, registration, forgot password)
- Jobs (main search bar, category directory, advanced filters & results, saved jobs, job alerts, applied jobs)

### 4.3 Strengths & Weaknesses

- **Strengths:** Mature information architecture, consistent navigation, rich filtering, strong candidate journey, employer-oriented workflow, scalable components.
- **Weaknesses:** High information density, repeated UI patterns, some accessibility gaps, complex navigation for new users, limited personalization in parts of the flow.

## 5. LinkedIn

### 5.1 Focus

Professional networking, with the deepest ecosystem beyond pure recruitment.

### 5.2 Survey Scope

The only survey to include a dedicated **design system** review:

- Platform overview (introduction, role in the professional ecosystem, user groups, key metrics, core value model)
- Design system & visual language (typography, color system, spacing & grid - each with evaluation and issues identified)

### 5.3 Strengths & Weaknesses

- **Strengths:** Mature information architecture, consistent navigation, rich filtering, strong candidate journey, employer-oriented workflow, scalable components.
- **Weaknesses:** High information density, repeated UI patterns, some accessibility gaps, complex navigation for new users, limited personalization in parts of the flow.

## 6. Comparative Matrix

| Feature         | VietNamWorks | TopCV    | LinkedIn  | Proposed Platform |

| Job Search      | ✓            | ✓        | ✓         | AI Search         |
| CV Builder      | ✓            | ✓        | Partial   | Advanced AI       |
| Networking      | Limited      | Limited  | Excellent | Enhanced          |
| Learning        | Basic        | Good     | Excellent | Personalized      |
| Messaging       | Basic        | Limited  | Excellent | Smart             |
| Recruiter Tools | Good         | Good     | Excellent | AI-first          |

This matrix is the clearest point of genuine differentiation in the source report - LinkedIn leads on networking, messaging, and analytics; VietNamWorks and TopCV are more evenly matched on core job-search functionality.

## 7. Proposed Next-Generation Platform

### 7.1 Keep

Strong search · Rich profiles · Recruiter dashboards · Company pages · Application tracking

### 7.2 Improve

Reduce visual clutter · Unify the design system · Improve accessibility · Better mobile UX · Faster onboarding

### 7.3 Add

AI recruiter assistant · AI career coach · AI resume optimizer · Interview simulator · Skill graph · Portfolio verification · Collaborative hiring · Explainable recommendations · Goal-based dashboard · Career roadmap

## 8. Conclusion

The three platforms converge on a standard recruitment workflow (search, apply, track, message) but diverge in ecosystem depth: LinkedIn leads on networking, TopCV on candidate preparation, and VietNamWorks on job-matching efficiency. A next-generation platform should merge these strengths into one AI-native, personalized, and more accessible experience.
